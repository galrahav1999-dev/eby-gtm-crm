# EBY GTM CRM — Decisions Log

Every notable choice, in plain language. Veto any line and I will change it.

## Product
- This is the EBY team's shared GTM workspace and single source of truth. It
  replaces the Google Sheet. Five-ish internal users.
- Feel: clean, immersive, lightly "game-like" (a world map of the GTM universe,
  smooth motion, dossier cards). NOT busy, NOT scoreboard-y.
- Two motions: B2B (schools/orgs) led, B2C (individual learners) as a hedge,
  plus a Partner/channel motion.

## Architecture
- **Stack:** Next.js 14 (App Router) + TypeScript + Tailwind, Supabase
  (Postgres + Auth), Vercel hosting. Reuses the cockpit design system + map/globe.
- **Database is the source of truth** (not the Sheet). 7 record tables +
  field_options + audit_log.
- **IDs:** every record has a hidden internal id and a human id (PER-/ORG-/DL-/
  PLT-/PTR-/INT-/WL-0000001) generated by the database. Kept for clean HubSpot
  migration later.
- **Editable dropdowns:** all dropdown values live in the `field_options` table
  and are managed from an in-app Admin screen. No redeploy to add/rename/hide an
  option. Code keeps the original lists only as seed + offline fallback. (Driven
  by EBY being in discovery: values change often.)
- **Mutations** use Next.js Server Actions (server-side, secure). Reads use
  Server Components. Writes go through a small service layer so a future HubSpot
  sync / Sheet mirror swaps in cleanly.

## Security
- Supabase Auth, invite-only (only emails the team adds can log in).
- Row Level Security on every table: any signed-in teammate can read/write all
  records (shared workspace). Owner is a data field, not a permission boundary.
- Service-role secrets, if ever needed, stay server-side only.

## Logging & observability (for KPIs, troubleshooting, RCA)
- **Audit log (in database):** every create/edit/delete writes actor + action +
  record + before/after. Surfaced in an in-app "Activity" view. Powers KPIs
  (interviews logged, records per owner, activity over time) and record-level RCA.
- **System errors + performance traces:** recommend **Sentry** (Next.js
  integration, free tier) wired at deploy. Vercel's native function logs cover
  basic infra logs. Alternative considered: Axiom/Better Stack log drains.

## Data import
- Seeded from the team's real "Discovery Contacts" tracker: 20 people, 2 orgs,
  1 interaction. IDs/keys preserved, every original note kept verbatim, nothing
  invented. "Misha" mapped to "Michael" (confirmed). Added country/city to People
  (B2C learners have a location but no org).

## AI logger
- Paste notes or a call transcript (speech-to-text); AI proposes draft records
  mapped to current dropdown options, with pains/quotes verbatim and "never
  invent" rules. Human reviews before saving. Audio-to-text (STT) upload is a
  follow-on. Uses the Claude API server-side (needs ANTHROPIC_API_KEY).
